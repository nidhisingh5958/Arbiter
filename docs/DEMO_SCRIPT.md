# Demo video script (under 3:00)

**Setup before recording:** deploy to Render (or run `make docker-up`) with `PAYPAL_MODE=sandbox`, `LLM_MODE=groq`, `POLICY_DISPUTE_WINDOW_SECONDS=20`. Log in to a PayPal sandbox **personal** (buyer) account in the same browser. Start on the home page, signed in as **Buyer**. Keep audio to voice only: no copyrighted music, and no third-party logos on screen.

| Time | Screen | Voice-over |
|---|---|---|
